# .ai — entorno de orquestación

Lo que define **cómo** trabajan los agentes (no qué es el producto). Punto de entrada: `AGENTS.md`.

- `registry/` — IDs de agentes y skills (`components.yaml`), capacidades, cobertura, ledger e índices generados.
- `policies/` — gobierno (quién aprueba qué), ciclo de vida de componentes, verificación y evidencias.
- `decisions/` — decisiones del entorno (EDR-NNN).
