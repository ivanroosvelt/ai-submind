# REQ-030 · Refresco en vivo de la UI

## Enunciado

La UI refleja cambios hechos por MCP o en disco sin recarga manual.

## Fuente

## Criterios de aceptación

1. Dado un cambio por MCP o en disco, cuando el motor lo aplica, entonces la UI abierta se actualiza.
